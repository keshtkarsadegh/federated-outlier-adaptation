# S8: plain FedAvg, the arm that can forget.
# An isolated client keeps its own model and drifts only as far as its own data
# pulls it. FedAvg averages every client's drift each round and sends the average
# back out as the next round's starting point, a hundred times over. That
# compounding is where forgetting comes from - so if this arm does not forget,
# there is nothing here for a regulariser or an aggregation rule to repair.
