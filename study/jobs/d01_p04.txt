# d01_p04.txt - Digits_study01, P04-P06: the populations, the books, the figure.
#
# P02 produced the detector: g-init (winner fold 3) and a score for every
# one of the 3,580 digit writers. This file cuts the cohort from that
# ranking, draws the old data around it, writes the two books, and banks
# the evidence a reader needs to argue with the selection.
#
# THE SCORES SELECT; THEY DO NOT BASELINE. g-init exists to rank writers
# and for nothing else. Every number this study reports is measured
# against g-0, which P07 trains on the old data drawn here.
#
# LINE 1 cuts the cohort: the 10 lowest-scoring writers that can form a
# local training split. --require-trainable is applied before the cut;
# on digits it removes nobody, because every one of the 3,580 writers
# splits (see d01_p02_README.md), but the flag stays so the rule is on
# the command line rather than in a footnote.
#
# LINE 2 draws the old data: 200 splittable writers holding at least
# 100 digit rows, seeded 20260827. A DRAW, not a ranking - taking the
# best or the largest writers would build the preservation reference out
# of an unrepresentative sample. 2,943 writers clear the 100-row bar
# (median holding is 117 digit rows), so the draw has room. The cohort is
# excluded: no writer is both an outlier and old data.
#
# LINES 3-4 write the two books: per-writer stratified 60/20/20 over 5
# folds, recorded as row indices, so one fold means the same rows in
# every process that ever opens them.
#
# LINE 5 IS AFTER THE BOOK ON PURPOSE. The cohort table reports each
# writer's per-fold train/val/test sizes, and those do not exist until
# the book does. Running it earlier would silently drop the column that
# makes the table worth banking.
#
# The table answers the two objections a ranking invites on its own:
# were these simply the writers with the least data, and were they the
# ones missing the hard classes? Each row carries the accuracy that
# selected the writer, its rank out of all
# 3,580, its digit rows, its per-class counts and its fold splits.
#
# LINE 6 draws the figure's REFERENCE population: 5 writers from the
# TOP of the ranking, seeded 20260828. 2,999 writers score exactly 1.0, so
# 'typical' is the overwhelming majority here and a seeded draw from it
# is well defined. The cohort is excluded so the two rows of the figure
# cannot share a writer.
#
# LINE 7 renders it: ten columns (every digit), three glyphs per writer,
# the reference population's mean digit on top. That top row used to come
# from the legacy writer_split.json, which this study never writes - the
# reference is now named on the command line and recorded in the figure's
# JSON sidecar, so what counts as 'typical' is stated rather than assumed.
#
# 7 tasks, all CPU, minutes each. A CHAIN: every line reads what an
# earlier one wrote.
#
foa select-outliers --results-dir $FOA_STUDY_DIR --resolution 28 --classes digits --mode worst --k 10 --require-trainable --tag digits_cohort10 --force
foa draw-old-data --results-dir $FOA_STUDY_DIR --resolution 28 --classes digits --size 200 --seed 20260827 --min-samples 100 --require-trainable --exclude-file $FOA_STUDY_DIR/outliers/cohort_worst10.json --out $FOA_STUDY_DIR/outliers/old_data.json
foa fold-book --results-dir $FOA_STUDY_DIR --resolution 28 --classes digits --out $FOA_STUDY_DIR/fold_books/cohort10 --clients-file $FOA_STUDY_DIR/outliers/cohort_worst10.json --folds 5 --seed 42 --train-rate 0.6 --eval-rate 0.2 --tag digits_cohort10
foa fold-book --results-dir $FOA_STUDY_DIR --resolution 28 --classes digits --out $FOA_STUDY_DIR/fold_books/old_data --clients-file $FOA_STUDY_DIR/outliers/old_data.json --folds 5 --seed 42 --train-rate 0.6 --eval-rate 0.2 --tag digits_old200
foa cohort-table --results-dir $FOA_STUDY_DIR --resolution 28 --classes digits --clients-file $FOA_STUDY_DIR/outliers/cohort_worst10.json --fold-book $FOA_STUDY_DIR/fold_books/cohort10.foldbook.npz --out $FOA_STUDY_DIR/tables/cohort_table.json --csv $FOA_STUDY_DIR/tables/cohort_table.csv
foa draw-cohort --results-dir $FOA_STUDY_DIR --resolution 28 --classes digits --best --k 5 --seed 20260828 --require-trainable --exclude-file $FOA_STUDY_DIR/outliers/cohort_worst10.json --tag digits_typical5 --out $FOA_STUDY_DIR/outliers/typical5.json
foa outlier-figure --results-dir $FOA_STUDY_DIR --resolution 28 --classes digits --outliers-file $FOA_STUDY_DIR/outliers/cohort_worst10.json --source-clients-file $FOA_STUDY_DIR/outliers/typical5.json --n-examples 3 --max-columns 10 --batch-size 256 --out $FOA_STUDY_DIR/tables/gallery/cohort_vs_typical.png
